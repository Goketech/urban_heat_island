## Re-generate

From project root:

```bash
source .venv/bin/activate
MPLCONFIGDIR="$TMPDIR/mplconfig" python src/generate_report_figures.py
MPLCONFIGDIR="$TMPDIR/mplconfig" python src/generate_chapter4_figures.py
```

Optional (higher resolution):

```bash
python src/generate_report_figures.py --dpi 600
python src/generate_chapter4_figures.py --dpi 600
```
